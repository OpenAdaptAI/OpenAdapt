| Opt-in fallback from a wrapped task's compiled program to the agent on drift: only when the hold is a terminal halt whose report is `HALTED_BEFORE_EFFECT` with no step needing reconciliation, bound to the admitted bundle, with zero replay model calls and a record check whose reads both succeeded and found no change. Never on `RECONCILIATION_REQUIRED`, a lost reply, `RECORD_CHECK_FAILED`, an unreadable system of record or a receipt that is not `VERIFIED`. The agent is built only once a fallback may start and runs through compile-agent's harness (right-record check, origin fence, read-back) with a person approving each save at a pre-commit gate (the terminal, or a signed item approval from a paired phone or `openadapt-flow item-approval approve`) and its own spend cap. A fallback is `VERIFIED` only when the final task-scoped read confirms the save; otherwise it is `RECONCILIATION_REQUIRED` with both readings kept. Its draft is never admitted, and a verified run opens a repair candidate for a person to approve.
