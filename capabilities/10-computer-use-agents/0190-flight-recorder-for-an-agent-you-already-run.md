| Flight recorder for an agent you already run: `openadapt flight -- CMD` puts a loopback proxy in front of the model API the agent calls (`ANTHROPIC_BASE_URL`, `OPENAI_BASE_URL`), meters and prices each call (an unpriced model's cost is recorded as unknown), honours a `--max-cost-usd` cap and logs each computer action. Scrubbing: the strings in the request (message text, tool-call arguments, tool results, URLs cut to their origin) and the screenshots it recognises (PNG, JPEG, GIF, BMP, TIFF, WEBP) are scrubbed before they are sent (see "What the scrubber does not cover" in FLIGHT_RECORDER.md); a request that can't be scrubbed is answered 502 and never sent, and the run refuses to start when openadapt-privacy, its spaCy model or tesseract is missing. Each value becomes a run token (`[PERSON_1]`, the same in text and on screen, painted over with the token written in); tokens in tool-call inputs are turned back into the real values before the response reaches the agent, so it can type them; the map stays local (`pseudonyms.json`, 0600). Measured on 50 synthetic records: 97.6 to 98.0% of fields in text and 97.2% in rendered screenshots, every miss a name; 93.1% of non-personal words on a synthetic work-list screen stay readable (30.9% with Presidio's image redaction). The agent still can't read a name it must check; task success with scrubbing on is not measured. The scrubber covers ordinary agent traffic in standard encodings (base64 in any wrapping, JSON escapes; image signatures are searched across the whole request and dense base64-like text refuses, per string and across the request). Images are recognised and scrubbed in PNG, JPEG, GIF, BMP, TIFF and WEBP; other image formats are refused only when the density backstops catch them, and a page with text on a flat background, uncompressed in another format, can get through; the backstops can refuse ordinary content that looks encoded (git SHAs, many camelCase identifiers, random tokens), and because the history is resent a refused turn refuses the rest of the run; an agent that deliberately re-encodes data (hex, percent-encoding, a custom scheme) can get it past the scrubber, so a hostile agent is out of scope and the egress block and provider choice are the controls there. Egress: on macOS the agent runs under `sandbox-exec` with outbound network denied except loopback; elsewhere `flight` refuses to run unless `--allow-unenforced-egress` is given (recorded). A run whose agent reports more model calls than the proxy saw, or that tried a direct call through the proxy variables, exits 3 and is marked refused; a kernel-blocked connection is blocked but not counted. Python API: `openadapt_flow.flight.egress.ScrubbedEgress`. Gate: a one-line executor swap (`GatedComputer` for the Anthropic computer tool, `GatedComputerCall` for an OpenAI `computer_call` loop) holds every action not known to be safe: a click or drag passes only on focus/view roles or a short list of labels (Cancel, Close, Back, Search, Open...; non-English and unreadable labels are held; OCR names a target only with text inside it); keys pass only on a short navigation list, or for editing inside a known text field; typing passes only when focus is known to be in a text field (from the accessibility hook, or the last click landed on one), and typed text with any control character is held; a focus move followed by more input in one action, Ctrl/Cmd+S, Ctrl/Cmd+Enter and any unknown action are held for a person (terminal y/N, or an item-approval request Desktop or a phone answers). It sees clicks and keys, not autosave. Writes `flight.json` (`openadapt.flight-run/v1`), `egress.json`, a scrubbed timeline and `timeline.html`.
