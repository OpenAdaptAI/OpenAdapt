# Changelog

## v0.1.0 (2026-11-25)

- Initial release of `openadapt-kernel` with zero `openadapt-flow` dependencies and zero per-app engine code.
- Added default-deny `ObligationLedger`, typed `<MANDATORY_CONSTRAINTS>` + `<VERIFIED_CAPABILITIES>`, SSA opaque-ID provenance, and durable Saga checkpointing.
- Added wire/DOM-effect `CommitInterceptor`, full-DOM `observe_schema` + transactional `stage_form`, and `StepwiseHealer` for live-mounted modal re-grounding.
- Added cross-rail read-back oracles (`verify_sqlite_ro`, FlateDecode PDF `3 Tr`/`7 Tr`-filtered `verify_pdf_readback`, and `verify_cross_tab_dom`).
- Added `ShadowObserver` multi-trace `PortalPack` induction, 4-mutant offline qualification, `MicroHandoffSession`, `probe_before_click` occlusion/hover check, `OnlineACICalibrator`, Ed25519 receipts, live CDP/Playwright `runner`, CLI (`openadapt-kernel`), and stdio JSON-RPC 2.0 MCP server.
